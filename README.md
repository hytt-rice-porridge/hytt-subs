# hytt-subs

This repo contains subtitles generated by the hytt-project.

## Layout

- `subtitles/<videoId>/` — one folder per YouTube video:
  - `<videoId>.<lang>.srt` — subtitle tracks
  - `<videoId>.metadata.json` — hytt run metadata
- `index.json` — the list of all video IDs that have subtitles

## Keeping `index.json` in sync (git hook setup)

`index.json` should always match the contents of `subtitles/`. The committed pre-commit hook takes care of this: it regenerates the index and stages it on every commit. Enable it once per clone:

```sh
git config core.hooksPath scripts/githooks
```

The hook (and the generator script it runs) requires [Bun](https://bun.sh).

The generator can also be run directly (outside of a Git hook):

```sh
bun scripts/generate-index.ts          # rewrite index.json
bun scripts/generate-index.ts --check  # verify it is up to date; writes nothing
```
